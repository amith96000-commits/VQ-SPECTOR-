# VQ-Spector

## AI-Powered On-Device Visual Quality Inspection

VQ-Spector is an edge-AI visual inspection system designed to assist quality-control operations in small and medium-sized manufacturing environments.

The system uses a camera and a Snapdragon-powered HP PC to analyze mechanical components and identify visible defects such as cracks, scratches, deformation, and missing features.

## Key Features

- AI-based visual defect detection
- Component inspection through a camera
- Local/on-device AI processing
- Defect classification
- Severity assessment
- Inspection recommendations
- Digital inspection records

## Proposed Workflow

Camera
→ Image Capture
→ AI Vision Analysis
→ Defect Detection
→ Severity Assessment
→ Inspection Recommendation
→ Digital Report

## Target Applications

- Small manufacturing units
- Machine shops
- Automotive component suppliers
- Fabrication industries
- Quality-control operations

## Technology

- Computer Vision
- Artificial Intelligence
- Python
- Snapdragon AI acceleration
- Qualcomm AI Hub models
- Windows on Snapdragon

## Project Status

Prototype under development.

The project will be evaluated and optimized for Snapdragon-powered HP PCs, with performance measurements added after testing on the target hardware.

## Vision

VQ-Spector aims to make intelligent visual inspection more accessible, portable, and practical for small-scale manufacturing.
